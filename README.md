# Juego de Adivinanzas en Java (consola)

Juego por consola: el programa elige un número entre 1 y 50 y el jugador tiene 5 intentos para adivinarlo, con pistas de mayor o menor.

## Características
- Número secreto aleatorio y límite de intentos.
- Pistas después de cada intento.
- Validación de entradas: texto y números fuera de rango no rompen el programa ni consumen intentos.
- Código separado en métodos de una sola responsabilidad.

## Requisitos
- Java 21 o superior (JDK)

## Cómo ejecutarlo
```bash
git clone https://github.com/franco-perdomo/juego-adivinanzas-java.git
cd juego-adivinanzas-java
javac -d out src/juegoadivinanzas/JuegoAdivinanzas.java
java -cp out juegoadivinanzas.JuegoAdivinanzas
```
